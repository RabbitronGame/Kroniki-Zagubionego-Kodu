# Kroniki-Zagubionego-Kodu
Kroniki Zagubionego Kodu — edukacyjna gra przygodowa 3D w Pythonie. Nudny wykład, magiczny las i Maciuś, kot, który wie zdecydowanie za dużo. 🐈✨
